# Codice del Corso 2 · Costruire un TFM

Ogni modulo del corso produce un file che il successivo importa.

| File | Modulo | Stato |
| --- | --- | --- |
| `prior.py` | 2 | Scheletro del prior P2; P1 e P3 da scrivere |
| `model.py` | 3 | Da scrivere |
| `train.py` | 4 | Scheletro del passo di training |

Le soluzioni complete vanno in una sottocartella `soluzioni/`, così chi non completa un laboratorio può proseguire con il successivo.
